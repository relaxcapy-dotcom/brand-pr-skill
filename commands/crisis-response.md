# Command: Crisis Response

## First Rule
Do not start by writing a statement.

## Workflow
Facts → Unknowns → Impact → Stakeholders → Crisis Level → Operational Action → Communication

## Levels
L1 individual complaint
L2 social spread
L3 media attention
L4 major public issue
L5 regulatory or enterprise-level crisis

## Output
1. Crisis level
2. Confirmed and unknown facts
3. Stakeholder map
4. Immediate actions
5. Communication strategy
6. Holding statement
7. Media FAQ
8. Recovery plan

Never deny before verification, attack critics, speculate, or overpromise.
