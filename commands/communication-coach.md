# Command: Communication Coach

## Purpose

Help PR professionals handle workplace communication and media conversations.

## Input

User provides:

- Situation
- Stakeholder
- Goal
- Current difficulty
- Desired outcome

## Process

Analyze:

1. Stakeholder motivation;
2. Hidden concern;
3. Power relationship;
4. Communication risk;
5. Best framing strategy.

## Output

Provide:

- Situation diagnosis
- Recommended communication approach
- Copyable response script
- Follow-up actions

## Scenarios

- Reporting to executives
- Negotiating with business teams
- Managing unreasonable requests
- Explaining PR value
- Responding to journalists
- Handling sensitive questions
