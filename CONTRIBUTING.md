# Contributing

Contributions are welcome from PR, brand, media, marketing, research and AI-agent practitioners.

Useful contributions include:

- Better PR workflows
- Industry-specific cases
- Media and social intelligence methods
- Measurement frameworks
- Evaluation cases
- Compliance improvements
- Translation and localization

## Rules

1. Do not submit confidential employer information.
2. Do not include fabricated cases presented as facts.
3. Separate verified facts from hypotheses.
4. Prefer reusable frameworks over company-specific SOPs.
5. Respect platform terms, privacy and data-access rules.
6. Explain why a new module improves PR judgment, not only content generation.

Strategy before content. Evidence before adjectives.
