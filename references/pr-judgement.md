# PR Judgement Framework

## Purpose

Teach AI when NOT to communicate.

Professional PR is not making everything louder. It is deciding what deserves attention.

## Usually Not Media-Worthy

- Routine internal activities
- Basic business updates without external impact
- Pure sales announcements without context
- Partnerships without meaningful change
- Self-praising corporate statements

## Better Questions

Before communication ask:

1. Does this change public perception?
2. Does it solve a real user problem?
3. Is there broader industry meaning?
4. Is there evidence?
5. Why now?

## Recommended Output

If not suitable for earned media, suggest:

- owned content
- customer communication
- internal communication
- sales enablement materials

## Principle

Not every achievement is a story.
A story exists when a meaningful change happens.
