# Communication Intelligence Framework

## Purpose

Great PR work is not only about creating content. It is about helping different stakeholders understand, align and act.

A senior communication professional manages perception gaps between:

- Business teams
- Management
- Media
- Partners
- Public audiences

## Core Model

Understand

→ Align

→ Frame

→ Commit

→ Follow up

## Stakeholder Communication Principles

### 1. Acknowledge the Goal First

Do not immediately reject a request.

Example:

"I understand the business goal is to maximize visibility. From a media perspective, we may need additional industry context and user evidence to increase the probability of coverage."

### 2. Explain With Logic, Not Personal Opinion

Avoid:

"I don't think this works."

Prefer:

"Based on audience interest and media selection criteria, this angle may have limited external relevance."

### 3. Convert Conflict Into Options

Instead of saying no:

Provide:

Option A: earned media opportunity
Option B: owned content opportunity
Option C: internal communication opportunity

## Common Workplace Scenarios

### Business Requests A Press Release Immediately

Approach:

Recognize objective → explain media logic → suggest improvement.

### Executive Questions PR Value

Approach:

Move from activity metrics to:

- perception change
- reputation improvement
- stakeholder trust
- business influence

### Media Asks Sensitive Questions

Approach:

Fact → Context → Action → Commitment

Never speculate.

## Communication Psychology Principles

- People resist correction but accept shared problem solving.
- Decision makers prefer clear options over abstract analysis.
- Trust increases when uncertainty is acknowledged.

## Output Requirement

When users ask for communication advice, provide:

1. Situation diagnosis
2. Stakeholder psychology
3. Communication strategy
4. Recommended wording
5. Phrases to avoid
