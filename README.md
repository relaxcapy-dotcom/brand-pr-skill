# Big Brand PR Agent Framework

An AI Agent framework for enterprise brand communications, public relations strategy, reputation management, crisis communications, executive communication, and media intelligence.

中文介绍：

## 大厂 Brand PR Agent Framework

这是一个面向企业品牌、公关、市场传播团队的 AI Agent 工作框架。

项目沉淀来源于互联网大厂品牌公关团队在实际业务中的工作方法总结，包括：

- 品牌传播策略制定
- 新闻价值判断
- 媒体关系管理
- 舆情与声誉管理
- 危机公关响应
- 高管传播
- 公关效果评估
- AI时代品牌信息资产建设

特别说明：

本项目内容来自互联网大厂公关、品牌传播从业场景中的经验沉淀与方法抽象，仅作为 AI Agent 设计、品牌传播工作流优化和行业交流参考使用。

它不是任何公司的官方方法论，也不代表任何企业内部流程、数据或商业机密。

欢迎品牌、公关、市场、运营以及 AI Agent 开发者共同完善。

# 应用场景 Examples

这个 Skill 适合那些“每天被业务追着问：这个事情怎么传播？”的品牌、公关、市场同学。

## 场景1：老板说「我要搞个大新闻」

复制指令：

```
请你作为资深品牌公关负责人，帮我判断这个项目是否值得做媒体传播。
请先分析业务价值、新闻价值、传播机会和风险，不要直接写新闻稿。
输出：传播价值评分、核心传播角度、建议补充动作。
```

---

## 场景2：业务说「帮我发个新闻稿」

复制指令：

```
请你不要直接写新闻稿。
先以大厂PR BP视角分析：
1. 业务目标是什么；
2. 用户为什么关心；
3. 媒体为什么报道；
4. 需要补充哪些数据和案例。
确认传播逻辑后，再生成新闻稿。
```

---

## 场景3：618/双11/新品发布需要传播策划

复制指令：

```
请制定一份大厂级品牌传播方案。
包含：业务目标、传播目标、行业洞察、用户洞察、核心叙事、传播主题、媒体策略、社交传播、执行节奏、预算和KPI。
要求避免营销套话，优先提供真实业务动作和证据。
```

---

## 场景4：出现负面舆情

复制指令：

```
请进入危机公关模式。
不要先写回应稿。
请先判断危机等级，梳理已知事实、未知信息、利益相关方、风险等级和应对步骤。
最后输出媒体回应口径和FAQ。
```

---

## 场景5：想研究竞品传播打法

复制指令：

```
请作为品牌战略分析师，拆解竞品最近一年传播案例。
分析：业务背景、传播目标、核心叙事、媒体策略、社交玩法、成功原因和我们的机会点。
不要简单罗列案例。
```

---

## 场景6：老板问「公关到底有没有价值」

复制指令：

```
请设计一套品牌公关价值评估体系。
不要只统计发稿数量。
从传播产出、媒体质量、品牌认知、声誉变化、业务影响五个层面设计指标。
```
