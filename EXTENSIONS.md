# Extensions — Recommended Capability Stack

Big Brand PR Agent Framework works best as the PR judgment and workflow layer. For live intelligence, connect compliant research and data capabilities.

## Recommended Stack

### 1. Web / Browser Research
Use for current news, policy, competitor activity, media coverage and source verification.

### 2. Social Listening
Use authorized or compliant sources for Xiaohongshu, WeChat Official Accounts, Douyin, Weibo and other public social conversations.

Recommended tasks:
- topic trend discovery
- consumer language mining
- KOL/KOC mapping
- comment theme analysis
- competitor narrative comparison

Do not bypass platform access controls or collect private data.

### 3. Data Analysis
Use for campaign dashboards, share of voice, sentiment trends, media quality scoring and KPI reporting.

### 4. Search / AI Visibility
Use for brand entity consistency, AI answer monitoring, citation-source analysis and narrative accuracy.

### 5. Creative Production
Use for campaign concepts, key visuals, social assets and presentation production after strategy is confirmed.

## Suggested Workflow

Research → Social Listening → PR Judgment → Strategy → Content → Distribution → Reputation Monitoring → Measurement

## Tool Selection Principle

Do not scrape merely because scraping is possible. Prefer official APIs, licensed databases, public search results, user-provided exports and compliant third-party tools.
