# PR Application Examples

This directory contains practical scenarios for applying Big Brand PR Agent Framework.

## Typical Scenarios

### 1. New Product Launch

Prompt:

```
请作为大厂品牌公关负责人，帮我设计一个新品上市传播方案。
先分析市场背景、用户洞察、传播机会，再设计媒体、社交和内容策略。
不要直接写广告文案。
```

### 2. Corporate Milestone

Prompt:

```
请判断公司的周年节点是否值得做品牌传播。
分析新闻价值、行业价值、用户价值，并提出更有传播力的叙事方式。
```

### 3. Crisis Communication

Prompt:

```
请进入危机公关模式。
先梳理事实、风险等级、利益相关方和行动方案，再设计回应口径。
```

### 4. Competitor Benchmark

Prompt:

```
请拆解竞品传播案例。
从业务动作、传播目标、媒体策略、用户认知和可复制经验几个维度分析。
```

## Principle

The framework helps communication professionals think before writing.
