# PR Prompt Cookbook

## 互联网大厂公关牛马急救包

## 1. 老板说：我要一个刷屏事件

```
请作为大厂品牌策略负责人，不要直接给创意。
先分析：
业务目标、用户情绪、社会趋势、品牌资产和传播机制。

然后输出3个具有传播可能性的事件方案。
每个方案包含：
- 核心洞察
- 为什么是现在
- 为什么适合这个品牌
- 用户参与机制
- 风险
```

---

## 2. 业务只给三句话，让我明天发稿

```
请先不要写新闻稿。
作为PR BP分析：
这个事情是否具有新闻价值？
如果不足，请告诉我需要补充哪些数据、案例或用户价值。
```

---

## 3. 竞品突然上热搜

```
请分析竞品热点事件。
不要只总结新闻。
拆解：
- 事件背景
- 用户情绪
- 传播机制
- 媒体打法
- 我们是否应该跟进
- 可复制机会
```

---

## 4. 突发负面舆情

```
请进入危机公关模式。
不要立即输出回应稿。
先判断：
事实、风险等级、利益相关方、需要确认的信息。
然后给出响应方案和FAQ。
```

---

## 5. 给老板做传播汇报

```
请按照互联网大厂总监汇报方式输出。
结构：
业务目标
传播目标
行业洞察
核心策略
执行方案
预算
KPI
风险
决策事项
```
