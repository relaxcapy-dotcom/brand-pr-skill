# Installation Guide / 安装指南

## Big Brand PR Agent Framework

## Overview

This skill can be used with compatible AI agent environments.

It provides:

- PR strategy workflows
- Media communication frameworks
- Reputation management methods
- Crisis communication playbooks
- Brand communication templates

---

# Quick Start

## Method 1: GitHub Clone

```bash
git clone https://github.com/relaxcapy-dotcom/brand-pr-skill.git
```

Review:

- SKILL.md
- commands/
- references/
- templates/

---

# Using with AI Coding Agents

Copy the skill folder into your agent skill directory according to your tool documentation.

Recommended:

1. Keep SKILL.md as the entry point.
2. Keep references available for reasoning.
3. Use commands as reusable workflows.

# First Test Prompt

Copy:

```
请作为资深品牌公关负责人，分析我的项目是否值得传播。
不要直接写稿。
先判断：
1. 业务目标；
2. 用户价值；
3. 新闻价值；
4. 媒体兴趣；
5. 风险。
最后给出传播建议。
```
